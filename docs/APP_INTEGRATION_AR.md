# تعليمات دمج العميل B

هذه مهمة لاحقة داخل YouTroc؛ لم يعدل هذا المشروع تطبيق Android.

## التحميل والتحقق

1. حمّل JSON من رابط HTTPS الثابت في README باستخدام اتصال مباشر منفصل عن البروكسي النشط، مع مهلة وحد أقصى 1 MiB. لا تقبل عنوان مصدر يقدمه JSON.
2. اقبل schema_version=1 فقط. تحقّق من generated_at وexpires_at ومن تواريخ كل عنوان. ارفض الملف المنتهي أو المؤرخ في المستقبل بأكثر من هامش ساعة الجهاز المقبول. لا تجدّد تواريخ التخزين المؤقت عند فشل التحديث.
3. اقبل HTTP والعناوين العامة IPv4 والمنافذ 1..65535 فقط؛ أعد التحقق محليًا، حتى لو قام الخادم بذلك. تجاهل الحقول الإضافية للتوافق المستقبلي، وارفض القياسات غير المحدودة/السالبة.
4. خذ حتى 20 عنوانًا صالحًا من النتائج المرتبة. حالات sources_unavailable وno_working_proxies لا تحتوي عناوين بديلة ضمنية. أبقِ وضع المستخدم DIRECT/MANUAL/FREE_POOL محفوظًا دون تبديل خفي.

## الاختيار المحلي

الكود الحالي في YouTrocProxyController.discoverWorkingFreeProxy يقرأ نص ProxyScrape ويعيد أول عنوان ينجح. استبدل مصدر المرشحين بملف JSON؛ أضف DTO في طبقة data ومصدراً قابلاً للاختبار. احتفظ بـ ProxyEndpoint وProxyProtocol وProxySettingsStore الموجودة في domain.

- اختبر حتى 20 مرشحًا، بتوازٍ محدود 3 وبمهلة كلية 30 ثانية قابلة للإلغاء.
- استخدم اتصالًا جديدًا محدد البروكسي لكل محاولة، بدون إعادة محاولة تلقائية أو fallback مباشر، والتحقق المعتاد لشهادة TLS.
- استخدم GET لـ YouTube generate_204 مع قبول 204 فقط وغياب جسم الاستجابة. الفحص الحالي الذي يقبل 200..399 يحتاج تشديدًا حتى لا ينجح عنوان يعيد تحويلًا أو صفحة تسجيل دخول.
- اختبر المرشحين الناجحين مرتين، واختر أقل وسيط زمن محلي. عند تقارب الأزمنة، يمكن استعمال اختبار تنزيل محلي محدود للفصل بينهم؛ قياس GitHub لا يتفوق على القياس المحلي.
- خزّن زمن الفحص ومدة صلاحيته مع العنوان. غيّر activeFreeEndpoint مرة واحدة بعد اكتمال الاختيار؛ لا تغيّر إعدادات التطبيق أثناء كل اختبار.
- ألغِ المهام المتبقية بعد انقضاء ميزانية الفحص. عند تغيّر الشبكة أو انتهاء الصلاحية أو فشل البروكسي النشط، أعد الفحص مع backoff بدل الدوران المستمر.
- عند عدم وجود نتيجة، أظهر الحالة بصدق واحتفظ بسياسة fallback المعتمدة للمستخدم. لا تمرر بيانات الدخول عبر البروكسي العام.
- استدعِ آلية إفراغ connection pools الحالية عند تبديل العنوان. حافظ على ProxyAuthIsolationPolicy وعلى استثناء OAuth وحسابات Google.

## اختبارات قبول التطبيق

JSON مشوّه؛ نسخة مخطط غير مدعومة؛ ملف أو عنوان منتهي؛ قائمة فارغة؛ فشل بعض المصادر؛ ترتيب الخادم مختلف عن المحلي؛ رفض عنوان خاص؛ تحويل HTTP؛ فشل TLS؛ مهلة وإلغاء؛ تبديل الشبكة؛ عدم تغيير البروكسي قبل اختيار الفائز؛ بقاء OAuth مباشرًا؛ fallback وفق إعداد المستخدم. استخدم محاكاة الشبكة أو محاكي Android، ولا تختبر على التلفاز حاليًا.
